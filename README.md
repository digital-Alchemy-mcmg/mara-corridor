# Spatial DNA project state

This branch preserves the transferred Spatial DNA materials as source artifacts, readable extractions, and a qualified project-state record. It is a preservation branch. No application was built, executed, wired, or merged by this work.

Start with [`spatial-dna-project-state/README.md`](spatial-dna-project-state/README.md). The originals are preserved without edits. Extracted text, tables, coordinates, and payload examples point back to their sources. The file manifest includes SHA-256 values. The `DNA` and `ENGine` branch snapshots are evidence of those branch tips, including empty placeholders; they are not claims of runnable code.

The default-branch training workbook remains at the repository root. Its binary bytes differ from the newly transferred `spatial dna training.xlsx`; both are preserved.
